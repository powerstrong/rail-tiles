# Rail Tiles

격자 위에 레일을 놓아 작은 기차를 출발역에서 도착역까지 데려다주는 싱글플레이 퍼즐 웹게임입니다.
백엔드 없이 브라우저만으로 실행됩니다.

현재 상태: **v1.5. 월드 9개 · 스테이지 300개 + 오늘의 퍼즐(기차·펭귄·차고지·우주 정거장·시계탑·화물역), 보스·보너스 스테이지, 새 규칙 안내 카드, 기차 꾸미기, 앱 설치, 기록 저장 코드.**
들꽃 기차 마을(40판), 강바람 철도(50판), 펭귄 얼음 나라(30판), 로봇 공장(30판), 화산 섬(30판), 기차 차고지(30판), 우주 정거장(30판), 시계탑(30판). 별 도전, 힌트, 드래그 배치  
플레이: https://powerstrong.github.io/rail-tiles/

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # Vitest 단위 테스트
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/)
npm run stages     # 스테이지별 정답 경로 수, 최소 레일 수, 정답 그림 출력
npm run difficulty # 스테이지별 난이도 점수(배포 전 확인용)
```

### 배포

**GitHub Pages:** https://powerstrong.github.io/rail-tiles/

`main`에 푸시하면 `.github/workflows/deploy.yml`이 테스트, 빌드, 배포를 자동으로 실행합니다.
빌드는 상대 경로(`base: './'`)를 쓰므로 다른 정적 호스팅(Cloudflare Pages 등)에도
빌드 명령 `npm run build`, 출력 디렉터리 `dist`로 그대로 올릴 수 있습니다.

|---|---|---|
| 레일 놓기 | 도구 선택 후 빈칸 클릭 | 도구 선택 후 빈칸 탭 |
| 여러 칸 한 번에 놓기 | 누른 채로 드래그 | 꾹 누른 채로 드래그 |
| 회전 | 놓인 레일 클릭 | 놓인 레일 탭 |
| 종류 바꾸기 | 다른 레일 도구로 놓인 레일 클릭 | 다른 레일 도구로 놓인 레일 탭 |
| 지우기 | 지우개 도구로 클릭(드래그로 여러 칸) | 지우개 도구로 탭(드래그로 여러 칸) |

| 출발 | `Enter` 또는 출발 버튼 | 출발 버튼 |

새 레일은 이웃한 레일과 역을 보고 연결되는 방향으로 자동으로 놓입니다.
드래그로 놓으면 끌고 간 순서대로 서로 이어지게 놓이고(빈칸만 채움), 드래그 한 번은 되돌리기 한 번으로 취소됩니다.
기차는 손님 칸에서 잠깐 멈추고, 손님이 인사한 뒤 올라탑니다.
직선이 놓인 칸을 곡선 도구로 누르면 직선은 회수되고 곡선으로 바뀝니다(반대도 같음). 실패해도 배치는 그대로 남습니다.
헤더의 스피커 버튼으로 효과음을 끄고 켤 수 있습니다(설정은 저장됨).
클리어 화면에서는 다음 스테이지, **배치 고치기**(놓은 레일 유지), **처음부터 다시**(빈 판, 힌트 제한 해제),
오른쪽 위 X 버튼(스테이지 목록으로)을 고를 수 있습니다.

### 오늘의 퍼즐

- 6스테이지(첫 손님)를 깨면 스테이지 목록 맨 위에 **오늘의 퍼즐**이 열립니다. 날짜마다 새 맵이 나오고,
  같은 날에는 모든 기기에서 같은 퍼즐입니다(날짜를 시드로 쓰는 결정적 생성).
- 생성기(`src/engine/generate.ts`)가 무작위 맵(6×6 또는 7×7, 장애물 덩어리, 손님 0~2명)을 그리고,
  솔버로 모든 정답 경로를 센 뒤 퍼즐다운 맵만 고릅니다: ★★★ 정답 1~2개, ★★/★ 경로 2개 이상,
  최단 경로가 판 크기보다 길고 곡선 4개 이상. 레일 수량은 최단 경로가 쓰는 만큼 + 약간의 여유입니다.
- 생성은 Web Worker에서 돌아 화면이 멈추지 않고, 결과는 그날 하루 기기에 캐시됩니다.
- 매일 클리어하면 **연속 기록(🔥 N일 연속)**이 쌓입니다.
- `npx vite-node scripts/daily-report.ts 2026-10-19 30`으로 날짜별 생성 시간, par, 별 분포를 점검합니다.

### 별과 힌트

- 스테이지마다 **par**(이길 수 있는 최소 레일 수)가 있습니다. par 이하로 클리어하면 ★★★, par+2 이하면 ★★, 그 외는 ★입니다.
- 레일은 넉넉히 주어집니다. 돌아가는 길로도 클리어할 수 있지만 그러면 ★★나 ★가 되고, ★★★는 최단 경로를 찾아야 합니다.
- 튜토리얼(1, 11)을 제외한 모든 스테이지에서 ★★★가 아닌 클리어가 가능한지 테스트로 보장합니다.
- **힌트** 버튼은 정답 레일 한 칸을 보여 줍니다. 힌트를 쓰면 이번 클리어는 최대 ★★입니다.
  주행에 실패한 뒤 누르면 기차를 출발역으로 되돌리고 힌트를 보여 줍니다.
  클리어 화면의 **처음부터 다시**나 스테이지 재입장으로 힌트 제한이 풀립니다.
- 가장 좋은 기록이 저장됩니다(진행 데이터 v2. 예전 v1 기록은 클리어당 ★1로 자동 이전).

## 기차 꾸미기 · 앱 설치 · 기록 지키기

- **기차 꾸미기**(처음 화면): 모든 월드에서 모은 별로 기차 색, 지붕 색, 연기(하트·별·음표·비눗방울·무지개·반짝이),
  장식(깃발·리본·꽃·스티커·왕관·천사 날개·반짝반짝 오라)이 열립니다. 별 8개부터 870개까지 43가지가 조금씩 열리고,
  뒤로 갈수록 금색·무지개·보석·황동·오로라·은하수·자정의 시계탑·축제 꽃가루처럼 화려해집니다. 모든 아이템은 정규 스테이지 별(최대 900개)만으로 열립니다(테스트로 확인). 고른 모습은 모든 월드의 기차와 처음 화면에 그대로 나옵니다.
  새로 열리면 화면 위에 선물 알림이 뜨고, 처음 화면 버튼에 NEW 표시가 붙습니다. 데이터는 `src/ui/look.ts`.
- **앱으로 설치하기**(처음 화면, 브라우저에서만 보임): Chrome·삼성 인터넷은 바로 설치 창을 띄우고, iPhone Safari와
  카카오톡 같은 앱 안 브라우저에서는 홈 화면에 추가하는 방법을 그림과 함께 알려 줍니다. `public/manifest.webmanifest`,
  앱 아이콘(`public/icon-*.png`), 오프라인용 서비스 워커가 있어서 한 번 열고 나면 인터넷 없이도 열립니다.
  서비스 워커(`dist/sw.js`)는 빌드할 때 `scripts/serviceWorker.ts`가 만듭니다: 빌드 결과 파일 전부를 처음 방문 때 미리 받아 두고,
  배포마다 새 캐시를 만들어 옛 캐시는 지웁니다. 페이지와 스크립트는 늘 같은 버전의 캐시에서 나오고,
  새 버전은 다음에 열 때부터 보입니다(새 버전 파일을 모두 받은 뒤에 넘어감).
  저장 코드는 압축(`RT1.z`)이 안 되는 브라우저에서 압축 없는 코드(`RT1.j`)로 만들어집니다.
- **기록 지키기**: 기록은 브라우저(localStorage)에만 있으므로, 별과 꾸미기를 담은 저장 코드(`RT1.`로 시작)를 만들어
  복사하거나 카톡 등으로 보내 둘 수 있습니다. 코드를 붙여 넣으면 지금 기록과 합쳐 더 좋은 별만 남깁니다.

## 월드

타이틀 다음은 **다음 정거장은?** 노선도입니다. 맨 위 **중앙역 광장**에는 차고(기차 꾸미기)·게시판(모든 월드의 오늘의 퍼즐,
완료 체크와 연속 기록)·우체통(기록 지키기)이 있고, 그 아래로 월드 역들이 해금 관계 그대로 선로로 이어집니다(`src/ui/routeLayout.ts`가
각 월드의 `unlockAfter`로 선로를 만들고, `src/ui/RouteMap.tsx`가 그림). 역이나 건물을 누르면 꾸민 내 기차가 선로를 따라 달려가고
(달리는 중 다른 곳을 누르면 짧은 쪽으로 방향을 바꿈, 동작 줄이기 설정이면 순간이동), 아래 안내 카드의 버튼은 기차를 기다리지 않고 바로 눌립니다.
잠긴 역은 흐린 원판과 점선 선로로 남아 있고, 누르면 여는 조건을 알려 줍니다.
**이어하기:** 마지막으로 연 판을 기억해(진행 데이터의 `last`), 타이틀과 노선도 아래의 버튼 한 번으로 그 판(또는 깼다면 다음 판)에 바로 들어갑니다(`src/continue.ts`).

예전 월드 목록 화면의 설명: 월드마다 퍼즐 종류와 테마가 다르고, 앞 월드의
**1장 보스(1-10)**를 깨면 다음 월드가 열립니다. 길은 두 갈래라서, 카드마다 번호 대신 어느 월드 다음 정거장인지("○○ 다음")를 보여 주고
같은 노선끼리 이어서 늘어놓습니다. 잠긴 월드도 소개 문구는 보이고, 여는 조건은 🔒와 함께 작게 붙습니다.
월드를 여는 판을 깨면 클리어 카드에 **"🚂 새 정거장이 열렸어요! ○○"**가 나오고, 열렸지만 아직 가 보지 않은 월드
카드에는 **NEW** 표시가 붙습니다(도착 이야기를 보거나 그 월드에서 별을 따면 사라짐, `openedNote`·`untouched` in `src/worlds.tsx`).

```
들꽃 기차 마을 ─┬─ 펭귄 얼음 나라 ── 로봇 공장 ── 화산 섬
                ├─ 강바람 철도 ─┬─ 기차 차고지
                │               └─ 우주 정거장 ── 시계탑
                └─ 선물 화물역
(이어진 앞 월드의 1-10을 깨면 열림)
```

| 월드 | 열리는 때 | 퍼즐 | 챕터 |
|---|---|---|---|
| 들꽃 기차 마을 | 처음부터 | 레일을 깔아 기차를 도착역까지 | 기본 선로 · 산과 터널 · 교차로와 분기기 · 손님 배달 (4×10판) |
| 펭귄 얼음 나라 | 들꽃 기차 마을 1-10 | 펭귄을 밀면 부딪힐 때까지 미끄러짐. 자기 색 낚시 구멍에 딱 멈추면 성공 | 얼음 미끄럼 · 이글루와 친구들 · 바다와 해류 (3×10판) |
| 로봇 공장 | 펭귄 1-10 | 거울을 톡 눌러 돌려 레이저로 전구를 모두 켜기 | 거울 반사 · 빛 나누기 · 색깔 레이저 (3×10판) |
| 화산 섬 | 로봇 공장 1-10 | 돌을 놓고 분출! 용암이 집에 닿지 않게 막기 | 마을 지키기 · 용의 알 · 작은 화산 (3×10판) |
| 강바람 철도 | 들꽃 기차 마을 1-10 | 같은 레일 퍼즐에 새 장치 | 건널목 · 도개교 · 급수탑 · 회전판 · 화물 열차 (5×10판) |
| 기차 차고지 | 강바람 철도 1-10 | 객차를 밀어 기관차가 출구로 나갈 길 만들기 | 차고지 탈출 · 건널목 버튼 · 기관차 두 대 (3×10판) |
| 우주 정거장 | 강바람 철도 1-10 | 중력 버튼 하나로 모든 캡슐이 한 칸씩 함께 날아감. 모두 자기 색 도킹장에 동시에 있으면 성공 | 중력 조종실 · 부스터 연구소 · 웜홀 정거장 (3×10판) |
| 시계탑 | 우주 정거장 1-10 | 생쥐가 한 칸 가거나 쉴 때마다 시계가 똑딱. 바뀌는 탑 사이로 박자를 맞춰 치즈 문까지 | 똑딱 블록 · 시계 바늘 · 거꾸로 레버 (3×10판) |
| 선물 화물역 | 들꽃 기차 마을 1-10 | 크레인으로 같은 선물을 모아 화차를 채우면, 기관차가 맨 앞 화차부터 데려감 | 맨 앞 화차부터! · 출발 전광판 · 크고 작은 화차 (3×10판) |

예전에는 앞 월드를 끝까지 깨야 열려서 시계탑까지 112판, 화산 섬까지 67판을 깨야 했습니다. 새로 시작한 아이도
뒤쪽 월드를 해 볼 수 있게 모든 문을 1장 보스로 당겨서, 이제 어느 월드든 30판 안에 열립니다(가장 먼 화산 섬 29판,
시계탑 28판). 각 월드의 1장이 그 월드 규칙을 처음부터 가르치고, 강바람 철도는 들꽃 기차 마을 2~4장의 터널·분기기·색깔
손님을 쓰지 않으므로 1-10 뒤에 바로 와도 됩니다. 새 문은 옛 문보다 앞에 있는 판이라 이미 열었던 사람이 다시 잠기는
일은 없습니다(`src/worlds.test.ts`가 옛 문 → 새 문을 확인).
다 깬 월드에는 **여행 완료!** 배지가 붙습니다.

**도착 이야기:** 월드에 처음 들어가면 꾸민 내 기차가 그 월드 정거장에 들어오고, 그곳 친구가 세 마디로 사정을
이야기합니다. 대사마다 장면이 바뀌며 그 월드의 문제와 푸는 방법을 그림으로 보여 줍니다.

| 월드 | 친구 | 장면 |
|---|---|---|
| 들꽃 기차 마을 | 역장님 | 꽃 흔들리는 마을 → 끊긴 선로 너머 손님들의 “?” → 레일 두 조각이 놓이고 기차가 건너가 손님들 ♥ |
| 펭귄 얼음 나라 | 분홍 펭귄 | 눈 내리는 역, 펭귄이 배로 미끄러져 와 눈사람에 쿵 → 낚시 구멍을 지나쳐 바위에 쿵 → 새 바위 덕에 구멍 위에 멈추고 물고기 퐁 |
| 로봇 공장 | 공장 로봇 | 컨베이어가 돌고 로봇이 삐빅 켜짐 → 정전으로 어두워지고 벨트 멈춤 → 레이저가 거울에 꺾여 전구가 하나씩 켜짐 |
| 화산 섬 | 섬마을 농부 | 파도 치는 섬, 화산이 우르릉 흔들림 → 용암이 마을로 흘러내려 집에 “!” → 돌 두 개가 막고 용암이 식음 |
| 강바람 철도 | 기관사 | 바람에 나무가 흔들리고 풍차가 돎 → 차단기·도개교·급수탑 이름표 → 차단기가 열리고 다리가 내려가 기차가 강을 건넘 |
| 기차 차고지 | 차고지 반장님 | 호루라기, 기차가 꽉 찬 차고지로 → 앞을 막은 객차에 덜컹 → 객차가 비켜나고 출구로 빠져나감 |
| 우주 정거장 | 우주 비행사 | 별빛 선로 끝 우주, 별똥별 → 중력 ↓에 캡슐 셋이 함께 떨어짐 → 중력 →에 각자 도킹장으로 쏙 |
| 시계탑 | 시계탑 생쥐 | 노을 진 시계탑, 바늘이 12시로 돌고 종이 울리면 작은 문에서 생쥐 → 박자 블록 앞에서 “?” → 박자에 맞춰 건너 치즈로 |
| 선물 화물역 | 화물역 너구리 보따 | 축제 깃발이 걸린 역에 기차가 들어옴 → 크레인 아래 선물이 뒤죽박죽인 화차에 “?” → 크레인이 정리하고 맨 앞 화차가 리본을 묶고 출발 |

**작별 장면:** 월드의 모든 판(보너스 포함)을 깨고 스테이지 목록으로 돌아가면 한 번, 고쳐진 월드에서 친구들이 축하하고
그 월드다운 선물을 기차에 실어 준 뒤 기차가 떠나며 다 같이 “안녕!” 합니다. 이미 다 깬 월드는 다음에 들어갈 때 한 번 나옵니다.

| 월드 | 작별 장면 |
|---|---|

| 로봇 공장 | 전구가 파티 조명처럼 색을 바꿈 → 로봇이 반짝이 전구를 기차에 → “삐빅 안녕!” |
| 화산 섬 | 식은 용암 길 옆 마을에 ♥ → 아기 용이 알에서 나오고 섬 과일 바구니 선물 → 화산이 하트 연기를 뿜으며 배웅 |
| 강바람 철도 | 바람에 연이 날고 → 급수탑 물을 기차에 가득 → 바람 따라 출발 |

| 시계탑 | 생쥐가 치즈를 냠냠 → 종을 한 번 더 울려 음표가 기차로 → 생쥐가 작은 문으로 돌아가 “안녕~” |
| 선물 화물역 | 친구들이 받은 선물 위로 하트가 퐁퐁 → 보따가 리본 선물 상자를 기차에 → 다 같이 “안녕!” |

장면을 누르면 기차가 바로 도착하고, **건너뛰기**로 넘길 수 있습니다(동작 줄이기 설정이면 처음부터 도착한 장면).
한 번 본 이야기(또는 이미 별을 딴 월드)는 다시 나오지 않고, 스테이지 목록 위 📖 버튼(도착)과 "모든 노선 완성!" 띠의 👋 작별 인사 버튼(다 깬 월드만)으로 언제든 다시 볼 수 있습니다.
대사는 `src/ui/stories.tsx`, 장면은 `src/ui/story/`(월드마다 한 파일에 도착·작별 장면, 공통 부품은 `kit.tsx`)입니다. 본 이야기는
진행 데이터의 `stories`에 저장됩니다(도착은 월드 id, 작별은 `월드id:bye`).

새 규칙이 처음 나오는 판(예: 펭귄 1-3 눈더미, 로봇 2-1 반투명 거울, 화산 3-1 작은 화산)에서는 처음 들어갈 때
**"새로 나왔어요!" 카드**가 그림과 함께 규칙을 알려 줍니다(그 판을 깨면 더 나오지 않음).

### 보스와 보너스 스테이지

- 모든 월드에서 챕터의 마지막 판은 **보스**(보라색 카드와 표시)이고, 그 챕터에서 가장 어렵습니다.
- 로봇 공장은 챕터마다 5번째 판이 **보너스 "로봇 구출 작전"**입니다(로얄매치의 킹의 악몽 참고).
  누를 때마다 로봇 배터리가 한 칸씩 줄고, 배터리가 바닥나기 전에 전구를 모두 켜야 합니다(되돌리기 없음, 실패해도 바로 재도전).
- 화산 섬은 챕터마다 5번째 판이 **보너스 "마을 대피 작전"**입니다. 용암이 이미 흐르고 있어서,
  돌을 하나 놓을 때마다 용암이 한 칸씩 번집니다. 집에 닿기 전에 용암을 가둬야 합니다(되돌리기 없음).
  보너스는 선택 사항이라, 깨지 않아도 다음 판이 열립니다.

### 강바람 철도 규칙

들꽃 기차 마을의 기차 시즌 2입니다(들꽃 기차 마을 1-10을 깨면 열림). 레일을 깔고 출발하는
재미는 그대로 두고, 챕터마다 기차가 달릴 때 눈에 보이는 기믹을 하나씩 더합니다.

- **건널목:** 버튼(`K1`)을 지나가면 같은 색 차단기(`D1`)가 올라갑니다. 닫힌 차단기에 닿으면 멈춤.
- **도개교:** 레버(`L1`)를 지날 때마다 같은 색 다리(`═1` `║1`)가 내려가거나 올라갑니다. 처음부터 내려가 있는 다리도 있음.
- **급수탑:** 증기기관차는 💧 숫자만큼만 달릴 수 있고(`water`), 급수탑(`F`)을 지나면 가득 찹니다. 달리는 동안 물이 줄어드는 게 보임.
- **회전판:** 회전판(`↻` `↺`)에 들어가면 화살표 쪽으로 빙글 돌아 나갑니다. 어느 쪽에서 들어가도 됨.
- **화물 열차:** 화물칸(`O`)을 지나가면 기차 뒤에 철컥 연결되어 따라옵니다. 모두 연결해야 도착 성공.
- 챕터마다 5번째 판은 **보너스 "한 번에 출발"**: 출발 기회가 한 번뿐이고, 실패하면 처음부터 다시(깨지 않아도 다음 판이 열림).
- 규칙은 `src/engine/step.ts`(`enter`, `signalPass`) 한 곳에 있고 `simulate`와 솔버가 같이 씁니다.
  색의 열림/닫힘과 남은 물은 분기기 상태처럼 기차 상태에 들어가서, 무한 루프 판정도 그대로 정확합니다.
- 판 만들기: `npx vite-node scripts/rail2-search.ts 사양.ts`. 무작위 판에 기믹을 놓고 풀어 본 뒤, ★★★ 정답 1~2개와
  ★★/★ 정답이 함께 있게 레일 개수를 정하고, 그 챕터 기믹을 ★★★ 정답이 꼭 쓰는 판만 고릅니다.
  테스트(`src/stages/season2.test.ts`)가 정답·최소 레일·별 분포·기믹 사용·난이도 곡선을 확인합니다.

### 기차 차고지 규칙

강바람 철도 1장 보스(1-10)를 깨면 열립니다.

- 차마다 자기 선로가 있어요: 가로 차는 좌우로, 세로 차는 위아래로만 길이 빌 때까지 미끄러집니다. 차 하나를 한 번 끌면 몇 칸을
  가든 이동 1번이고, 같은 차를 연달아 끌면 한 번으로 셉니다(그 이동을 시작한 자리로 되돌리면 취소되고, 취소나 되돌리기 뒤에는
  그 전 차를 다시 끌어도 새 이동으로 셉니다). 기관차는 길이 비면 자기 깃발이 달린
  출구로 나갑니다. 모든 기관차가 나가면 성공입니다. 차를 고른 뒤 같은 줄의 빈칸을 눌러도 되고, PC는 방향키와 글자 키(`r` `b` `A`…).
- 객차는 두 칸, 화물차는 세 칸, 급수탑과 상자는 움직이지 않습니다.
- **건널목(챕터 2):** 다른 차가 노란 버튼 위에 서 있는 동안만 차단기가 열립니다. 움직이는 차는 자기 자신을 위해 버튼을 누르고 있을 수
  없고, 닫힌 차단기는 들어오는 차만 막습니다(이미 올라선 차는 나갈 수 있음).
- **기관차 두 대(챕터 3):** 빨강·파랑 기관차가 각자 자기 색 깃발 출구로 나가고, 먼저 나간 기관차는 길을 비켜 줍니다.
  파란 기관차는 내 기차와 겹치지 않는 색으로 칠해집니다(빨간 기관차는 '기차 꾸미기'에서 고른 모습).
- 챕터마다 5번째 판은 **보너스 "출발 시각!"**: 정해진 횟수 안에 내보내야 하고 되돌리기가 없습니다(깨지 않아도 다음 판이 열림).
- 별: 최소 이동 이하 ★★★, +2 이하 ★★. 힌트는 지금 상태에서 가장 빠른 다음 이동을 화살표와 점선 칸으로 보여 줍니다.
- **오늘의 차고지 퍼즐:** 1-4를 깨면 열립니다. 요일마다 종류가 달라요(수요일 건널목, 금·토 기관차 두 대, 일요일은 둘 다).
- 엔진은 `src/depot/`: `slide.ts`(규칙 하나로 화면과 솔버가 공유), `solver.ts`(상태 전체 너비 우선 탐색, 최소 이동·최단해 수·힌트),
  `audit.ts`(난이도), `generate.ts`(무작위 차고와 오늘의 퍼즐), `stages.ts`(30판). 모든 이동은 되돌릴 수 있으므로, 생성기는 무작위
  차고 하나의 모든 배치를 탐색한 뒤 원하는 최소 이동 수가 걸리는 배치를 시작 상태로 고릅니다.
- 판 만들기: `npx vite-node scripts/depot-search.ts 사양.ts`. 크기, 기관차와 출구, 차 수, 건널목, 최소 이동 범위와 목표 난이도를 적으면
  목표에 가장 가까운 판을 정의로 출력합니다. 테스트가 정답·최소 이동·챕터 기믹·버튼이 꼭 필요한지·난이도 곡선을 확인합니다.
- 난이도 점수: 최소 이동 + 선택 정보량(정답 길에서 log2(가능한 이동 / 가까워지는 이동)의 합) × 0.5 + log2(배치 수) × 0.8
  − log2(최단해 수) × 0.5. 첫 판 6 → 15 → 17, 보스 40 → 50 → 55로 다른 월드와 비슷합니다.

### 우주 정거장 규칙

강바람 철도 1장 보스(1-10)를 깨면 기차 차고지와 함께 열립니다. 캡슐을 하나씩 고르지 않는다는 점이 다른 월드와 다릅니다.

- **중력 버튼**(화살표 4개, 보드 위 스와이프, PC는 방향키·WASD)을 한 번 누르면 **모든 캡슐이 그쪽으로 한 칸씩 동시에** 날아갑니다.
  벽·소행성·정거장 가장자리에 막히거나, 앞에서 막힌 캡슐에 막히면 그 자리에 멈춥니다. 아무것도 움직이지 않는 누름은 세지 않습니다.
- 모든 캡슐이 **같은 시각에** 자기 색(모양) 도킹장에 있으면 성공. 한 캡슐을 벽에 기대 두고 다른 캡슐만 따라잡게 하는 게 핵심입니다.
- **부스터(챕터 2):** 날아 들어간 캡슐만 화살표 쪽으로 한 칸 더 밀려납니다(원래 서 있던 캡슐은 그대로).
- **웜홀(챕터 3):** 날아 들어간 캡슐은 같은 색 짝 웜홀로 나옵니다. 짝 웜홀이 막혀 있으면 들어간 자리에 그대로 있습니다.
- 한 번 누를 때 **중력 → 부스터 → 웜홀**이 한 번씩 차례로 일어나고, 단계마다 모든 캡슐이 동시에 움직입니다.
  두 캡슐이 같은 칸으로 가려 하거나 서로 자리를 바꾸려 하면 둘 다 멈추므로, 캡슐 순서와 상관없이 결과가 늘 같습니다(`src/space/gravity.ts`).
- 캡슐이 다시는 도킹할 수 없는 자리에 빠지면 팁 자리에 "되돌리기나 처음으로를 눌러 봐요" 안내가 뜹니다(판을 열 때 모든 배치를 미리 계산).
- 챕터마다 5번째 판은 **보너스 "산소가 부족해!"**: 정해진 횟수 안에 도킹해야 하고 되돌리기가 없습니다(깨지 않아도 다음 판이 열림).
- 별: 최소 누름 이하 ★★★, +2 이하 ★★. 힌트는 지금 배치에서 가장 빠른 다음 방향을 보드 위 화살표와 버튼 불빛으로 보여 줍니다.
- **오늘의 우주 정거장 퍼즐:** 3-1(웜홀)을 깨면 열립니다. 요일마다 종류가 달라요(수·목 부스터, 금 웜홀, 토 웜홀 두 쌍, 일요일은 둘 다).
- **생각이 필요한 판만:** 처음 배우는 판(1-1~1-3, 2-1, 3-1)을 빼면, 캡슐을 도킹장 쪽으로만 끌어당기는 단순한 플레이로는
  ★★★를 받을 수 없습니다(`naivePresses`, 테스트로 확인). 오늘의 퍼즐도 같은 기준으로 만듭니다.
- 엔진은 `src/space/`: `gravity.ts`(규칙), `solver.ts`(모든 배치 너비 우선 탐색·최소 누름·힌트), `audit.ts`(난이도), `generate.ts`(판 찾기), `stages.ts`(30판).
- 판 만들기: `npx vite-node scripts/space-search.ts scripts/space-specs.ts [id ...]`. 무작위 정거장의 모든 배치를 탐색한 뒤,
  원하는 누름 수만큼 떨어진 배치를 도킹장 자리로 골라 목표 난이도에 가까운 판을 출력합니다(부스터·웜홀이 있으면 그것 없이는 더 오래 걸리는 판만).
  테스트가 정답·최소 누름·챕터 기믹·부스터와 웜홀이 꼭 필요한지·난이도 곡선을 확인합니다.

### 선물 화물역 규칙

들꽃 기차 마을 1장 보스(1-10)를 깨면 펭귄 얼음 나라·강바람 철도와 함께 열립니다. 선물은 다른 월드 친구들에게 가는
물고기(펭귄)·꽃(들꽃 마을)·치즈(시계탑)·별(우주)·수박(화산 섬)·톱니(로봇 공장)입니다.

- 화차를 누르면 크레인이 **맨 위의 같은 선물을 한꺼번에** 들고, 다른 화차를 누르면 내려놓습니다(빈 화차나 같은 선물 위, 들어갈 만큼만).
  크레인 한 번이 1수입니다. PC는 숫자 키 `1`~`7`로 화차를 고르고 `Esc`로 취소, `Ctrl+Z` 되돌리기.
- 한 가지 선물로 꽉 찬 화차는 **리본**으로 묶여 더는 짐을 뺄 수 없습니다.
- **기관차는 맨 앞 화차만 데려갑니다.** 맨 앞 화차가 리본으로 묶이면 출발하고, 줄이 한 칸씩 앞으로 당겨지며 맨 뒤에 같은 크기의
  빈 화차가 붙습니다. 새 맨 앞도 묶여 있으면 바로 따라 출발합니다(**줄줄이 출발**). 그래서 맨 앞을 마지막에 채우고 뒤를 먼저 준비하는
  판단이 핵심입니다.
- **출발 전광판(챕터 2):** 맨 앞 화차는 전광판에 반짝이는 선물로 묶여야 떠납니다. 다른 선물로 묶이면 줄이 막혀 되돌리기를 안내합니다.
- **크고 작은 화차(챕터 3):** 두 칸·세 칸·네 칸 화차가 섞입니다. 떠난 화차와 같은 크기의 빈 화차가 맨 뒤에 붙으므로 크기 순서도 같이 돕니다.
- 챕터마다 5번째 판은 **보너스 "축제 기차"**: 크레인 한 번에 2대(3장은 3대)를 줄줄이 출발시켜야 클리어입니다(깨지 않아도 다음 판이 열림).
- 별: 최소 크레인 횟수 이하 ★★★, +2 이하 ★★. 힌트는 지금 상태에서 가장 빠른 한 수를 화살표로 보여 줍니다. 더는 선물을 다 보낼 수 없는
  상태가 되면 바로 알려 줍니다(판을 열 때 Web Worker가 모든 상태를 미리 계산).
- **오늘의 화물역 퍼즐:** 1-4(줄줄이 출발)를 깨면 열립니다. 일찍 열리는 대신 1장 규칙(세 칸 화차, 전광판 없음)만 쓰고, 요일마다 화차 수·선물 종류·연쇄 조건이 달라요.
- **생각이 필요한 판만:** 처음 배우는 판(1-1~1-3)을 빼면, 바로 보낼 수 있는 것부터 보내거나 큰 더미를 쌓거나 화차를 깔끔하게만 유지하는
  세 가지 단순한 플레이로는 ★★★를 받을 수 없습니다(`naiveMoves`). 또 줄 규칙(맨 앞만 출발)과 전광판이 없으면 더 빨리 풀리는 판만 골라서,
  두 규칙이 늘 답을 바꿉니다(`parAnyWagon`, `parNoBoard`). 테스트가 모두 확인합니다.
- 엔진은 `src/cargo/`: `yard.ts`(규칙 하나로 화면과 솔버가 공유), `solver.ts`(모든 상태 너비 우선 탐색·최소 수·힌트), `audit.ts`(난이도),
  `generate.ts`(판 찾기·단순 플레이·오늘의 퍼즐), `stages.ts`(30판), `CargoScreen.tsx`(크레인·출발 애니메이션).
- 판 만들기: `npx vite-node scripts/cargo-search.ts scripts/cargo-specs.ts [id ...]`, 손으로 만든 판 점검은 `scripts/cargo-check.ts`.
- 난이도 점수: 최소 수 + 선택 정보량 × 1.1 + log2(상태 수) × 0.7 − log2(최단해 수) × 0.5 + 막다른 비율 × 6 + 기다린 화차 × 0.8.
  첫 판 8 → 19 → 14, 보스 34 → 42 → 49.

### 시계탑 규칙

우주 정거장 1장 보스(1-10)를 깨면 열립니다. 길 찾기에 **타이밍**이 더해진 퍼즐입니다.

- 생쥐는 한 번에 한 칸 움직이거나(화살표·스와이프·방향키), **쉬기**(⏳ 버튼·생쥐 톡·스페이스)로 제자리에서 한 박자 기다립니다.
  움직임과 쉬기 모두 시계가 **똑딱** 한 번 가는 것이고, 치즈가 있는 문에 닿으면 성공. 최소 똑딱 수가 ★★★입니다.
- **똑딱 블록(챕터 1):** 빨강 블록은 짝수 똑딱, 파랑 블록은 홀수 똑딱에 올라옵니다. 내려가 있는 블록 위에는 설 수 있지만,
  다음 똑딱에 올라올 블록 위에서는 쉴 수 없어 미리 비켜야 합니다. 화면 아래에 "다음 똑딱: 빨강 ↑ 파랑 ↓"가 보입니다.
- **시계 바늘(챕터 2):** 바늘은 똑딱마다 축을 중심으로 시계 방향 90도씩 돕니다(1~3칸 길이). 똑딱이 끝났을 때 바늘이 덮는 칸에는
  있을 수 없고, 다음 바늘 자리가 흐린 그림자로 보입니다.
- **거꾸로 레버(챕터 3):** 레버 칸에 들어가면 그다음 똑딱부터 모든 바늘이 반대로 돕니다(다시 밟으면 원래대로). 블록 박자는 그대로입니다.
- 막힌 행동은 하지 않고 이유를 알려 줍니다("다음 똑딱에 블록이 올라와요", "시계 바늘이 지나갈 자리예요"). 더는 문에 갈 수 없는
  자리에 들어서면 되돌리기를 권합니다(판을 열 때 모든 상태를 미리 계산).
- 챕터마다 5번째 판은 **보너스 "자정의 종"**: 정해진 똑딱 안에 도착해야 하고 되돌리기가 없습니다(깨지 않아도 다음 판이 열림).
- **오늘의 시계탑 퍼즐:** 3-1(레버)을 깨면 열립니다. 요일마다 종류가 달라요(월 블록, 화·목 바늘, 수 블록과 바늘, 금·토 레버, 일요일은 모두).
- **생각이 필요한 판만:** 처음 배우는 판(1-1~1-3, 2-1, 2-2, 3-1)을 빼면, 문 쪽으로 걷다가 막히면 쉬기만 하는 단순한 플레이로는
  ★★★를 받을 수 없습니다(`naiveTicks`, 테스트로 확인). 미리 쉬거나, 일부러 돌아가거나, 레버를 들르는 판단이 꼭 들어갑니다.
- 상태는 (생쥐 칸, 바늘 각도 0~3, 바늘 방향) 하나의 정수이고, 블록 박자는 바늘 각도의 홀짝과 늘 같습니다(`src/clock/tick.ts`).
  `solver.ts`가 모든 상태를 너비 우선으로 탐색해 최소 똑딱·힌트·막다른 곳을 계산합니다.
- 판 만들기: `npx vite-node scripts/clock-search.ts scripts/clock-specs.ts [id ...]`. 무작위 탑에서 생쥐가 닿을 수 있는 모든 칸을 문 자리로
  시험해, 블록·바늘·레버가 하나라도 빠지면 답이 달라지는 판만 목표 난이도에 가깝게 고릅니다. 테스트가 정답·최소 똑딱·챕터 기믹·
  쉬기가 꼭 필요한 판·난이도 곡선을 확인합니다.

### 화산 섬 규칙

- 풀밭을 누르면 돌이 놓이고, 다시 누르면 치워집니다. **분출!** 버튼을 누르면 모든 화산에서 용암이 흘러나와
  위·아래·왼쪽·오른쪽으로 퍼집니다. 돌, 바위, 바다는 용암을 막습니다. 집에 용암이 닿으면 실패(돌은 그대로 두고 다시 시도).
- **뜨거운 땅:** 화산 바로 옆 칸에는 돌을 놓을 수 없습니다(화산만 빙 둘러싸는 쉬운 답을 막음).
- **용의 알(챕터 2):** 용암이 알에 닿아야 아기 용이 깨어납니다. 집은 지키고 알로 가는 길은 열어 둬야 합니다.
- **작은 화산(챕터 3):** 숫자만큼만 흐릅니다. 돌로 길을 빙 돌게 만들면 용암이 집까지 못 옵니다.
- 별: 최소 돌 개수 이하 ★★★, +2 이하 ★★. 힌트는 잘못 놓인 돌(빨간 점선)이나 다음에 놓을 칸(노란 원)을 보여 줍니다.
- 엔진은 `src/volcano/`: `lava.ts`(용암 흐름, 솔버, 대피 작전), `audit.ts`(난이도), `generate.ts`(무작위 판), `stages.ts`(30판).
  솔버는 "집으로 가는 가장 짧은 용암 길 위 어딘가에는 반드시 돌이 있어야 한다"를 이용해 그 길의 칸들로만 가지를 쳐서
  최소 돌 개수와 정답 전부를 찾습니다. 대피 작전은 (돌, 용암) 상태를 너비 우선으로 탐색합니다.
- 판 만들기: `npx vite-node scripts/lava-search.ts 사양.ts`. 모든 판은 테스트가 정답·최소 돌 개수·★★★ 정답이 하나뿐임을 확인합니다.
- 난이도 점수: 돌 × 3 + 용암이 닿는 풀밭에 그만큼 돌을 놓는 경우의 수(log2) × 0.9 + 집·알·작은 화산·화산 수
  + 집은 지키지만 알을 식히는 "차가운 오답" 수. 첫 판 7 → 18 → 16, 보스 42 → 53 → 55로 로봇 공장보다 조금 높습니다.

### 로봇 공장 규칙

- 레이저는 직진하다가 거울(`/` `\`)에서 꺾이고, 벽·판 끝·닫힌 문에서 멈추며, 전구와 센서는 그냥 통과합니다.

- **색깔:** 빨강·파랑 전구는 같은 색 빛, 보라 전구는 빨강과 파랑 둘 다, 일반 전구는 아무 빛이나. 색 필터는 같은 색만 통과.
- 별: 최소 누르기 횟수 이하 ★★★, +2 이하 ★★. 힌트는 지금 상태에서 가장 가까운 정답으로 가려면 돌려야 할 거울 하나를 표시합니다.
- 엔진은 `src/machine/`: `beam.ts`(빛 추적, 센서 문은 두 번 추적해 안정), `solver.ts`(모든 거울 조합 확인: 최소 횟수, 정답 수, 힌트),

- 판 만들기: `npx vite-node scripts/laser-search.ts 사양.ts`. 모든 판은 테스트가 정답·최소 횟수·유일한 ★★★ 정답과
  "보스가 챕터에서 가장 어렵다"를 확인합니다. 난이도는 첫 판 7 → 18 → 16, 보스 41 → 51 → 54(로봇 공장 점수 기준).


### 펭귄 얼음 나라 규칙

- 펭귄을 손가락으로 쓱 밀거나(스와이프), 화면 아래 화살표를 누르거나, 펭귄과 같은 줄의 칸을 누르면 그쪽으로 밉니다.

  물고기를 모두 먹으면 성공입니다(구멍 위를 미끄러져 지나가기만 하면 안 됨).

- **해류:** 지나가면 화살표 방향으로 꺾임. **금 간 얼음:** 펭귄이 한 번 떠나면 깨져서 바다가 됨.
- 별: 최소 밀기 횟수(par) 이하 ★★★, par+2 이하 ★★, 그 외 ★. 힌트는 지금 상태에서 가장 빠른 다음 한 수를 화살표로 보여 줍니다.
- 엔진은 `src/penguin/`: `slide.ts`(규칙 하나로 화면과 솔버가 공유), `solver.ts`(상태 전체 너비 우선 탐색, 최소 횟수·정답 수·힌트),
  `audit.ts`(난이도), `stages.ts`(30판). 모든 판은 테스트가 정답·최소 횟수·★★★ 정답이 하나뿐임을 확인합니다.
- **오늘의 펭귄 퍼즐:** 1-3을 깨면 펭귄 월드 목록 맨 위에 열립니다. 요일마다 종류가 달라요(월·화 펭귄 하나,
  수 이글루, 목 해류와 금 간 얼음, 금·토 펭귄 둘, 일요일은 펭귄 둘에 이글루와 해류인 작은 보스).
  날짜로 정해지는 판이라 모든 기기에서 같고, Web Worker에서 만들어 하루 동안 저장합니다. 연속 기록은 들꽃 기차 마을과 따로 쌓입니다.
- 1-1에서는 손가락이 첫 번째로 밀 방향을 보여 주는 안내가 나옵니다(한 번 밀면 사라짐).
- 판 만들기: `npx vite-node scripts/ice-search.ts 사양.ts`. 크기, 펭귄 수, 기믹 개수, 밀기 횟수와 난이도 범위,
  정답에서 꼭 써야 하는 기믹(`must`)을 적으면 무작위 판을 풀어 보고 조건에 맞는 판을 골라 줍니다.

## 스테이지

챕터 4개, 챕터마다 10판씩 모두 40판입니다. 판 번호는 `챕터-순서`(예: 2-5)로 표시합니다.
각 챕터는 쉬운 연습판으로 시작해 점점 어려워지고, 마지막 판이 그 챕터의 보스 판입니다.
앞 판을 깨면(별 1개 이상) 다음 판이 열립니다. 이미 깬 판은 항상 열려 있어서,
나중에 챕터 중간에 판이 추가되어도 예전 기록 때문에 막히지 않습니다.

| 판 | 챕터 1 · 기본 선로 | 챕터 2 · 산과 터널 | 챕터 3 · 교차로와 분기기 | 챕터 4 · 손님 배달 |
|---|---|---|---|---|
| 1 | 첫 번째 선로 (2) | 터널 통과 (10) | 교차로 (20) | 첫 배달 ★ (13) |
| 2 | 모퉁이 돌기 (9) | 강 밑 터널 ★ (14) | 한 바퀴 돌아 교차 ★ (18) | 분기기 배달 ★ (14) |
| 3 | 언덕 너머 (10) | 돌아서 들어가기 (14) | 선로 전환기 (13) | 터널 택배 ★ (15) |
| 4 | 강 건너기 (13) | 터널 너머 손님 ★ (14) | 반대로 놓인 분기기 (10) | 먼저 태우고 내려요 ★ (24) |

| 8 | 두 손님 (24) | 두 갈래 터널 (18) | 고리 모양 길 ★ (24) | 배달하고 태우고 ★ (41) |

★는 v0.6에서 새로 만든 판, 괄호는 난이도 점수입니다. 챕터 2~4는 점수가 올라가는 순서로 놓고,
새 규칙을 처음 배우는 판(예: 3-3 선로 전환기)에서만 한 번 쉬워집니다. 챕터 2~4는 마지막 판이 그 챕터에서
가장 어렵고(챕터 1은 1-8 두 손님이 보스보다 조금 어려움), 마지막 배달(4-10)이 게임 전체에서 가장 어렵습니다
(손님 셋, 터널, 교차 레일, ★★★ 정답 하나).

### 난이도 점수

`npm run difficulty`는 판마다 ★★★ 정답을 놓는 순서대로 한 칸씩 따라가며, 그 칸에 놓을 수 있어 보이는
다른 레일(기차가 빈 땅으로 계속 달리게 되는 것)을 하나씩 시험합니다. 솔버로 끝까지 풀어 봐서 절대 이길 수 없는
것이 **함정**, 다른 길로 이길 수 있는 것이 **갈림**입니다.
점수 = 함정 수 + log2(정해진 레일로 모든 정답을 찾는 데 든 솔버 탐색량).
대략 2는 바로 보이는 판, 10~15는 쉬움, 20은 챕터 1 마지막 수준, 30 이상은 어려움, 40 이상은 보스입니다.

**배포 전 확인:** 스테이지를 추가하거나 고치면 `npm test`(정답·par·경로 수 고정)와 함께
`npm run difficulty`를 돌려 챕터 안 순서와 보스 판이 맞는지 확인하고 나서 `main`에 올립니다.
기차·펭귄·로봇·화산 월드는 `src/difficulty.test.ts`가 난이도 곡선을 고정합니다: 다음 판은 최대 8점(보스는 10점)까지만
오르고, 4점 넘게 쉬워지지 않으며, 보스가 챕터에서 가장 어렵고, 새 기믹이 나오는 판은 앞 판보다 최소 횟수가 1 넘게
많지 않아야 합니다. 들꽃 기차 마을은 이 규칙보다 먼저 만들어져서 지금 어긋나는 9곳을 `known`에 그 크기와 함께 적어 두었습니다.
새로 어긋나거나, 적힌 곳이 더 나빠지거나, 고쳐졌는데 목록에 남아 있으면 테스트가 실패합니다(강바람 철도는 `season2.test.ts`).

### 기믹 규칙

- **터널:** 같은 글자의 두 입구가 연결됩니다. 입구가 열린 쪽으로만 들어갈 수 있습니다.
- **교차 레일:** 직선 두 개가 엇갈린 조각입니다. 기차는 언제나 곧게 지나가므로, 한 칸을 가로·세로로 한 번씩 두 번 지날 수 있습니다.
- **분기기:** 고정 배치입니다. 줄기 쪽에서 들어오면 지금 가리키는 갈래로 나간 뒤 방향이 바뀝니다. 갈래 쪽에서 들어오면 항상 줄기로 나갑니다. 등의 화살표가 현재 방향을 보여 줍니다.
- **손님 배달(챕터 4):** 손님마다 색이 있고, 같은 색 지붕 집이 목적지입니다. 손님 칸을 먼저 지나 태운 뒤
  집 칸을 지나면 내립니다(집을 먼저 지나면 아무 일도 없음). 모든 손님을 내려 줘야 도착역에서 성공입니다.
  기차는 손님이 타고 내릴 때마다 잠깐 멈춥니다.
- 같은 위치·방향·분기기 상태가 반복되면 무한 루프로 판정해 실패합니다.

### 핵심 설계

- **결과를 먼저 계산하고 재생:** `simulate()`가 기차 경로 전체와 실패 원인·위치를 계산하고,
  UI는 그 trace를 애니메이션으로 보여 주기만 합니다.
- **같은 기하 공유:** `geometry.ts`의 선분과 원호가 레일 SVG와 기차 위치 계산에 모두 쓰입니다.
  그래서 기차가 곡선에서도 레일 중심을 정확히 따라갑니다.
- **같은 규칙 공유:** `step.ts`의 `enter()` 하나가 이동 규칙을 정의하고, 주행 계산과 솔버가 모두 이를 씁니다.
- **루프 감지:** 분기기는 상태가 바뀌므로 (칸, 방향, 모든 분기기 상태)가 반복되면 무한 루프로 판정합니다.
- **스테이지 난이도 고정:** `stages.test.ts`가 스테이지마다 솔버의 해 개수를 고정해 둡니다.
  스테이지를 고쳐서 지름길이 생기면 테스트가 실패합니다.

## 스테이지 만들기

`src/stages/stages.ts`에 `StageDef`를 추가합니다. 맵 기호:

```
.  빈칸          P  승객(경유지)    S  출발역    G  도착역
T  나무   R  바위   M  산   W  물   H  집
│ ─ └ ┌ ┐ ┘   고정 레일
a b c …       터널 입구 (같은 글자 두 개가 한 쌍)
┼             고정 교차 레일
1 2 3 …       분기기 (switches 설정 필요)
A B C         배달 손님 타는 곳    X Y Z  각각 A B C 손님의 집(내리는 곳)
```

분기기는 `switches: { '1': { trunk: 'W', turn: 'N', initial: 'turn' } }`처럼 줄기 방향, 꺾이는 갈래 방향,
시작 방향(기본 straight)을 적습니다. 플레이어용 교차 레일 수는 `inventory.cross`(기본 0)입니다.

터널은 `tunnels: { a: ['E', 'W'] }`처럼 읽는 순서(위→아래, 왼→오)로 첫 번째·두 번째 입구가
열린 방향을 적습니다.

`║ ═`는 강 위의 고정 다리입니다. `solution`에는 같은 크기의 격자에 **최단** 정답 레일을 적고(레일 수가 par가 됨),
`stages.test.ts`의 `EXPECTED`에 ★★★ 경로 수와 전체 경로 수를 기록합니다.

새 스테이지 설계 순서:

1. 초안 맵을 `StageDef` 배열로 export하는 파일을 만듭니다(인벤토리와 solution은 임시값).
2. `npx vite-node scripts/autotune.ts 초안.ts`: 넉넉한 레일로 모든 정답 경로를 센 뒤, 최단 경로 하나의
   조각 수 근처에서 ★★★ 경로 1~3개, ★★/★ 경로가 생기는 수량을 골라 `solution`과 테스트 기대값까지 출력합니다.
3. 장애물 배치를 자동으로 찾으려면 맵에 `?`(무작위 장애물 후보)를 쓰고
   `npx vite-node scripts/stage-search.ts 초안.ts`를 실행합니다. 여러 번 장애물을 흩뿌려 보고
   별점이 의미 있고 경로가 깔끔한 맵을 점수순으로 보여 줍니다(`par: [최소, 최대]`, `density`,
   `mustUse: 'cross'` 같은 조건을 초안에 적을 수 있음).
4. 고른 맵을 `stages.ts`의 챕터 배열에 넣고 `stages.test.ts`의 `EXPECTED`를 기록합니다.
