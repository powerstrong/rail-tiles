# 03 합의안 (Claude 정리, 2026-11-15)

01 Claude 제안 ↔ 02 Codex(gpt-6-astra) 검토를 합친 결론. 사용자 확정 전.

## Codex 검토로 바뀐 것 (Claude가 받아들임)
- **펭귄도 화물역형 막힘이 있다**: 첫 판 `ice-first-slide`에서 위로 한 번 → 실패 안내 없이 완성 불가. 30판 중 24판. 이미 `explore()/toWin`이 있어 시계탑·우주처럼 매 이동 `has()` 조회로 고칠 수 있음 → 최우선.
- **꿀벌은 1번 판부터 함정**(출발→오른쪽 꽃이면 완주 불가, 30판 중 29판). "고립된 꽃 표시"로는 못 잡음 → 진입 시 전체 상태 그래프 1회 생성(최대 1,496 상태, ~4 ms) + 매 이동 조회 + 경로 되짚기. 이걸 통과해야 편입.
- **거울 토끼는 막다른 상태 0개**(전수 탐색) → 가장 확실한 편입.
- **강바람 50판 → 들꽃의 선택형 "장치 노선" 약 20판**: 화물=승객 방문과 같은 판단, `t2-busy-crossing`은 설명("차단기 두 개 모두")과 달리 하나만 지나도 깨짐. 기존 ID·해금(`t2-boss-1` → 차고지·우주)은 보존.
- **철도 빨리 감기**: 2× 버튼이 아니라 "빠르게 확인 + 운행 취소 후 바로 수정". 결과는 `simulate()`로 이미 계산돼 있음.
- **막힘 감지는 공통 솔버를 매 이동 돌리지 말고**, 작은 판은 진입 시 그래프/표를 만들어 조회. 판정은 가능 / 불가능 증명 / 미확인 3단계, 입력은 절대 잠그지 않음.
- **아이 관찰을 맨 앞으로**: 1명이라도 거울 토끼·꿀벌·펭귄 첫 3판, 철도 재시도를 시켜 본다.

## Claude가 유지한 반대 의견
- **달 토끼 "역도약으로 돌 되살리기"는 하지 않는다 → 삭제.** 돌이 하나씩 줄어드는 것이 이 장르의 쾌감인데, 되살리기 규칙은 그걸 없애고 사실상 새 게임이 된다. 규칙·힌트·검증을 전부 새로 해야 하는 비용도 크다(Codex도 우선순위 꼴찌로 둠). 코드는 archive 브랜치에 남겨 둔다.
- 변형 재시험은 **싼 것 2개만**: 산호초(par 이내면 진주 보너스, 실패 없음), 저울(쟁반 없애고 좌↔우 토글). 둘 다 규칙 1개·6판. 결과가 애매하면 삭제.
