### 막힘 판정의 정확성

- **펭귄 30판, 총 11,714개 상태, 최대 3,625개/판, 탐색 중단 0.** 24판에 막다른 상태가 있다. 추가 검증 스크립트에서 모든 상태의 판정을 확인했다. 가능 상태는 실제 합법 이동으로 완주 거리가 감소하는 증거가 있고, 불가능 상태의 모든 합법 후속 상태도 불가능 집합에 남으며, 승리 상태는 거리 0이다. 첫 판 위로 이동의 경고·복구·완료는 실제 브라우저에서도 통과했다.
- **꿀벌 30판, 총 7,381개 상태, 최대 1,496개/판.** 단위 테스트가 모든 도달 상태를 별도 DFS 결과와 대조한다. 첫 3판은 막힘 0, 이후 27판에는 막힘이 있으나 즉시 안내하고 복구할 수 있다. 되짚기까지 완주 탐색에 포함해 모든 상태를 “가능”으로 오판하는 방식이 아니다. 앞으로 꽃길을 이어 끝낼 수 있는지와 복구 조작을 분리했다.
- **거울 토끼 30판, 총 5,397개 상태, 최대 455개/판.** 전체 탐색 중단 및 막다른 상태 없음. 새 경고·입력 잠금이 필요하지 않은 근거를 확인했다.

아이에게 선택을 되돌릴 수 없다는 사실을 늦게 알리는 화물역형 실패는 펭귄·꿀벌의 새 경고와 복구로 해결됐다. 토끼의 “한 마리는 집에 왔는데 왜 다시 움직이나”는 명시적인 안내가 추가됐다. 알려진 막힘 자체가 없어진 것은 꿀벌 첫 3판이며, 후속 판은 막힘을 설명하고 복구하는 설계다.

### 기존 저장 데이터 호환

- `rail-tiles:progress`의 기존 v1→v2 읽기와 v2 저장 형식을 유지한다. 별 값, 꾸미기, 이야기 기록, 마지막 판을 검증·보존하며 다른 탭의 더 높은 별을 낮추지 않는다.
- 별도 실행에서 구 강바람 **50개 ID의 별 값을 모두 넣은 저장**을 읽고 다시 저장했을 때 50개 값과 부가 필드가 유지됐다. 내보내기/가져오기에서도 전체 별 값이 일치했다.
- 기존 50판의 진행 지점 0~50 각각을, 보너스 완료/건너뛰기 두 경우로 나눈 **102개 진행 경우**에서 남은 첫 미완료 판과 이미 완료한 판이 열려 있음을 확인했다. 단순히 보스 한 판의 해금만 확인한 것은 아니다.
- `t2-boss-1`의 기존 기록만으로 차고지·우주가 계속 열리는 것은 브라우저 테스트로 확인했다. 삭제된 판의 별은 전체 별·꾸미기 자격에 남고, 현재 코스 목록의 별 합계는 남은 20판만 센다.
- 정식 편입된 두 게임은 기존 ID를 유지한다. 이전 실험실은 원래 모든 판이 열려 있었으므로 과거에 뒤쪽 판만 완료한 경우, 그 완료 판 자체와 다음 판은 열리고 나머지는 새 정식 순차 해금 규칙을 따른다.
- 실제 기준 버전 빌드가 설치된 브라우저에 기존 두 localStorage 키를 넣은 업데이트 검증까지 수행했다. 새 버전에서 두 종류 도장이 별로 표시되고 강바람 기록·꾸미기가 유지됐다. N1의 삭제 판 이어하기 예외를 제외하면 기존 저장 때문에 시작할 수 없거나 기록이 지워지는 현상은 발견하지 못했다.
