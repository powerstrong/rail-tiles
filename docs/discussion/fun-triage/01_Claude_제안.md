# 01 Claude 제안 — 살릴 것 / 없앨 것 / 고칠 것

입력: `00_astra_재미순위.md` (gpt-6-astra, 2026-11-15). 실제 아이 플레이테스트는 없음.

## 판단 원칙 (화물역 삭제에서 배운 것)
재미 = ① 조작 직후 결과가 보인다 ② 실패가 싸다(막히면 즉시 알고 바로 되돌린다) ③ 장이 바뀔 때 *새 현상*이 생긴다(수가 늘어나는 것 ≠ 새 현상) ④ 완성하면 보고 싶은 것이 있다.
- **없애는 기준:** UI를 고쳐도 핵심 판단 자체가 재미없거나, 장르 특성상 "몇 수 뒤 막다른 길"이 본질이거나, 이미 정식 월드가 같은 재미를 더 잘 주는 경우.
- **살리는 기준:** 핵심 판단이 신선하고 위 ①~④ 중 빠진 것이 *구현으로* 채워지는 경우.
- 18개를 다 다듬는 것보다 개수를 줄이고 남은 것을 깊게 다듬는 편이 낫다.

## 공통 개선 (모든 퍼즐에 적용)
1. **막힘 즉시 감지**: 실험실은 이미 solver + hint worker가 있음 → 이동마다 백그라운드로 "풀 수 있는가"를 확인해, 불가능해진 순간 부드러운 표시 + "한 수 되돌리기" 버튼을 띄운다. (힌트를 눌러야만 알 수 있는 현재 방식이 화물역 문제의 재현.) 탐색 예산 초과는 "막힘"으로 표시하지 않음.
2. **운행 대기 줄이기(철도 계열)**: 들꽃/강바람의 승하차 1.2 s 정지 → 빨리 감기(2×) 버튼, 재시도 시 기본 빠름.
3. **첫 3판 = 규칙 하나씩 직접 해 보게**: 규칙 글을 읽는 대신 판이 가르친다.
