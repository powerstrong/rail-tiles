# 01 메모리 게임 초안 (Claude, 2026-11-15)

사용자 요청: "메모리 게임 넣자. 2개 맞추는 거, 같은 그림. 맞추면 그림 뒤집히기." Codex와 함께 설계·구현.

## 지난 교훈 (반드시 지킬 것)
- 화물역 삭제: 검증된 깊이 ≠ 재미. 함정 규칙, 늦게 드러나는 실패, **입력을 막는 애니메이션**이 재미를 죽였다.
- 30판을 먼저 만들지 말고 **느낌을 프로토타입으로 사용자에게 먼저 보여 준다.**

## 기본 규칙
- 카드가 뒷면으로 깔려 있다. 두 장을 뒤집는다. 같은 그림이면 짝 성공 → 두 카드가 "뒤집혀" 그림 면이 계속 보이는 상태로 남고 작은 축하(반짝 + 소리). 다르면 다시 뒷면으로.
- 모든 짝을 찾으면 완료. 시간제한·실패 횟수 제한 없음.

## 입력을 막지 않는 핵심 UX
- 틀린 두 장은 ~0.9초 보여 준 뒤 뒤집히지만, **그 사이 다음 카드를 누르면 즉시 두 장이 덮이고 새 카드가 뒤집힌다**(기다리게 하지 않음).
- 뒤집기 애니메이션은 짧게(~200 ms), prefers-reduced-motion 존중.

## 별(★) — 운 요소 고려
- 메모리 게임은 첫 뒤집기가 운이다. "최소 수"를 par로 쓰면 불공정.
- 제안: 짝 N개 기준 **실수(틀린 시도) 수**로 별. 예: 실수 ≤ N → ★★★, ≤ 2N → ★★, 완료 → ★. (완벽한 기억력이면 기대 실수 ≈ N 미만이라 넉넉함.) Codex가 시뮬레이션으로 기준 검증 요망.
- 힌트: "한 번 본 카드 중 짝이 있는 곳 살짝 반짝" 정도. 힌트 사용 시 최대 ★★ (기존 규칙).

## 진행 (3장 × 10판 = 30판, 단 프로토타입은 1장 10판만)
- 1장 "첫 짝꿍": 2×2(2쌍) → 2×3 → 3×4(6쌍)까지. 그림은 크고 확연히 다른 것.
- 2장 "닮은 친구들"(안): 비슷한 그림(같은 동물 다른 색/모자) 섞기 → 관찰력. *함정 아님: 다른 점이 분명히 보이게.*
- 3장 "큰 기억 정원"(안): 4×4~4×5(8~10쌍).
- 새 현상 후보(Codex 의견 필요): 짝을 찾으면 그 카드가 그림의 일부가 되어 **보드 전체가 하나의 그림으로 완성**되는 보상(완성 그림 수집). 짝 맞추기가 "그림 맞추기" 퍼즐이 되는 느낌.

## 세계관/그림
- 원작 게임 재현 없음. rail-tiles 세계관에 맞춰 "기차역 분실물 보관소"나 "숲 동물 친구" 테마의 자체 SVG/이모지 그림. 색만으로 구분하지 않도록 모양도 다르게(색약 배려, 기존 원칙).

## 통합
- 거울 토끼·꿀벌처럼 정식 월드로 등록(노선도 정거장, 별, 순차 해금, 이어하기). 기존 해금 보존, 일찍 선택 가능.
- 카드 배치는 판마다 고정 시드(다시 하기 시 같은 배치? 아니면 새로 섞기?) — Codex 의견 필요. 기억 게임은 다시 할 때 같은 배치면 외워서 풀게 되므로 **다시 하기마다 새로 섞기**가 맞아 보임(별 기준은 실수 수라 공정).

## 질문 (Codex에게)
1. 별 기준 실수 ≤ N / ≤ 2N 이 아이에게 적절한가 (기억 모델 시뮬레이션)?
2. 1장 10판의 보드 크기 곡선.
3. "보드가 하나의 그림으로 완성" 보상 vs 단순 축하 — 어느 쪽이 프로토타입 가치가 큰가.
4. 기존 코드 구조(src/lab/PuzzleScreen.tsx 공통 화면 vs 새 디렉터리)에서 어디에 넣는 게 맞나.
