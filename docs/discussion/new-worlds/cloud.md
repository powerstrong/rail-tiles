# 구름 자수 공방 정식 편입

2026-11-15. 월드 ID `cloud`. `archive/lab-v1`의 노노그램을 정식 노선도에 편입했다. 커밋·푸시·배포 없이 작업 트리만 수정했다.

## 규칙과 조작

숫자는 연속으로 수놓는 칸의 길이다. `2·1`은 두 칸 묶음과 한 칸 묶음 사이를 최소 한 칸 비운다. 위 숫자는 세로, 왼쪽 숫자는 가로이며 0은 모두 빈칸이다. `·`는 미확정, 색 있는 실땀 사각형은 수놓기, `×`는 확실한 빈칸이다. **모든 칸을 수놓기 또는 ×로 정하고 모든 줄의 숫자를 만족하면 완성**한다. 판마다 완료 규칙을 바꾸지 않는다.

수놓기·×·지우개를 직접 고른다. 같은 표시를 다시 누르면 지운다. 모든 표시는 자유롭게 고칠 수 있고, 되돌리기와 처음부터도 제공한다. 방향키로 칸 이동, Enter/Space로 표시, Ctrl/⌘+Z로 되돌리기를 지원한다. 시간·실패 횟수 제한과 입력을 잠그는 완료 연출은 없다. 완료 뒤에도 바로 되돌리거나 다음 판으로 갈 수 있다.

별은 공통 `starsFor()`를 사용한다. `par`는 모든 칸을 한 번씩 표시하는 수, par 이하 ★★★ / par+2 이하 ★★ / 나머지 완료 ★이다. 되돌린 조작은 횟수에서도 빠진다. 실제 논리 힌트를 받으면 이번 판 최대 ★★이며, 되돌리기로 이 제한을 해제할 수 없다. 처음부터는 제한을 초기화한다. 이미 저장한 더 좋은 별은 유지한다.

## 조작형 입문과 장별 설계

- **1장, 한 땀과 쉼표:** 1×1 한 번, 1×2 두 번으로 시작한다. 3판 1×4의 `2·1`, 4판 1×5의 `2·2`에서 묶음과 필수 ×를 직접 익힌다. 5판은 가운데 겹침, 6판은 3×3에서 가로·세로 전달을 익힌다. 7~10판은 4×4 작은 그림에 적용한다. 설명을 펼치거나 애니메이션을 기다려야 시작할 수 있는 구조가 아니다.
- **2장, 가로가 세로에게:** 5×5에서 이미 길이를 채운 묶음의 양옆을 닫고, 확정한 ×와 실땀을 반대 방향 줄의 제약으로 쓴다. 1·1·1, 2·2, 비대칭 묶음 등에서 ‘다음 칸 채우기’ 외에 ‘여기는 더 이어지지 않는다’를 판단한다.
- **3장, 겹침의 전시회:** 6×6에서 여러 묶음이 놓일 수 있는 범위를 비교한다. 창문 같은 빈 공간, 1·2·1과 2·2, 3·2처럼 서로 다른 길이, 비대칭 짧은 묶음을 조합한다. 단순히 같은 줄을 더 길게 누르는 대신 가능한 배치 사이의 공통 칸을 발견하도록 한다. 모든 판은 한 줄 추론을 반복해 끝까지 풀린다.

원래 30개 ID를 모두 유지한다. 첫 6판은 입문용으로 바꿨고 7~30판은 보관판의 도안을 유지했다. 기존 완료 기록을 취소하거나 재평가하지 않는다.

## 정답을 보지 않는 논리 힌트

`src/cloud/model.ts`의 힌트 입력은 **가로·세로 단서와 현재 표시뿐**이다. 작품 배열을 전달하지 않는다. 한 줄에 숫자 묶음을 놓을 수 있는 모든 배치를 구하고 현재 표시와 일치하는 것만 남긴다. 남은 모든 배치에서 같은 값인 미확정 칸만 제시한다.

힌트는 줄과 대상 칸을 강조하며, ‘단서 2·1: 묶음과 빈칸을 놓는 방법이 하나뿐’, ‘가능한 3가지 배치가 이 칸에서 모두 겹침’, ‘0은 모두 비움’처럼 이유를 짧게 설명한다. 같은 줄의 가능한 모양도 보여 주어 직접 비교할 수 있다. 제안된 한 칸을 적용하는 버튼과 기존 도구를 모두 사용할 수 있다.

현재 표시로 한 줄의 가능한 배치가 0개면 즉시 그 줄의 모순을 알리고 직전 표시 되돌리기를 제공한다. 이는 저장 정답과 비교한 오답 검사가 아니다. 모순은 없지만 확정할 칸도 없으면 찍도록 유도하지 않고 최근 표시를 되살펴보도록 한다. 어떤 표시도 지우거나 덮어쓸 수 있으므로 되돌릴 수 없는 막다른 상태 자체가 없다.

## 작품과 모바일

완성 즉시 플레이하던 판의 실땀에 색이 들어오고, 빈칸 ×는 사라져 도안 자체가 작품이 된다. 첫 판의 한 번 조작에서도 화면 안에 바로 변화가 보인다. 아래 완료 카드와 작품 모음에는 같은 색실과 실땀 모양을 가진 자체 SVG 작품을 보여 준다. 간단한 작품 모음은 공통 진행 기록으로 완성한 작품만 보여 주며, 새로고침 뒤에도 남는다. 미완성 도안의 답을 갤러리로 공개하지 않는다. 도구와 판의 상태는 색뿐 아니라 사각형·실땀·×·점으로 구분한다. 사운드는 기존 `src/ui/sound.ts`를 사용한다.

390×844 Chromium 터치 화면에서 첫 판 칸 **56×56px**, 마지막 판 칸 **44×44px**. 확대하면 **56×56px**, 판 내부 가로 스크롤로 이동한다. 숫자를 누르거나 칸을 선택하면 해당 줄이 강조되고, 가로 숫자는 스크롤할 때 따라온다. 320/390/844px에서 페이지 가로 넘침을 검사한다. 320px에서 넓은 판은 내부 스크롤로 유지해 칸을 줄이지 않는다.

스크린샷을 실제 열어 확인했다.

## 정식 통합과 저장 호환

`src/worlds.tsx`의 정식 월드 한 항목, 자체 SVG 엠블럼, 임시 노선도 좌표 `[298, 596]`, 도착·작별 이야기를 추가했다. 처음부터 선택 가능하며, 공통 스테이지 목록의 순차 해금·별·이어하기·다음 판·저장 코드 체계를 사용한다. 공유 파일의 변경은 cloud 항목 추가와 기존 전체 목록 기대값에 cloud를 추가하는 정도로 제한했다. 장치 노선 E2E의 고정 정거장 수 9개 기대는 새 월드 추가 때마다 실패하므로, 본래 목적에 맞게 장치 노선이 독립 역으로 나타나지 않는지를 검사하도록 한 줄 수정했다. 게임 구현·작품·도안·테스트는 `src/cloud`에 있다.

저장 스키마와 `src/storage.ts`는 변경하지 않았다. 기존 `lab-v1-cloud-1`~`30`을 그대로 사용하고, 구 실험실 저장의 유효 ID 허용 목록에 cloud를 추가해 예전 완료 도장을 ★1로 이관한다. 기존 더 좋은 별과 다른 월드 기록은 그대로 보존한다. 첫 6판을 재설계해도 과거 별을 낮추지 않는다.

## 검증과 재현

원본은 고정 수작업 도안 `src/cloud/patterns.json`이다. 런타임 무작위 생성은 없다. `npx vite-node scripts/cloud-generate.ts`는 고정 seed **3238862886 (`0xc10d2026`)**으로 확정 가능한 여러 조작의 순서를 골라 `proofs.generated.json`을 재생성한다. 두 번 생성한 SHA-256이 동일함을 확인했다: `4494c7c69b5f2ce63561534b10d3426134db2a2fa39e8ad064a084f406d1a5e4`.

- **30/30 유일해:** 가로 배치를 열거하고 세로 접두와 대조하는 별도의 탐색으로 해답 수가 정확히 1개임을 확인했다.
- **30/30 줄 추론 완주:** 실제 힌트 선택기를 반복 적용해 모든 칸이 확정된다. 분기·찍기·정답 참조가 없다.
- **30/30 해답 재생:** 생성된 해답의 매 조작마다 그 한 줄의 가능한 배치 전체가 해당 값을 지지하는지 검사하고, 마지막 그림과 도안이 일치하는지 확인한다.
- 2·1 필수 간격, 0 단서, 미확정/× 구별, 추론 불가 시 힌트 없음, 모순 시 추측 없음, 별 상한·저장 이관·순차 해금·이어하기를 단위 검증한다.

## 남은 문제

- 실제 초등학생 관찰과 실제 iOS/Android 기기 테스트는 하지 못했다. 자동 해답 검증은 재미나 이해의 실증이 아니다. 특히 첫 × 도구 발견, 6→7판의 판 크기 변화, 후반 겹침 이유를 스스로 말할 수 있는지 관찰해야 한다.
- 노선도 좌표는 병렬 월드 편입 뒤 최종 통합 배치가 필요하다.
- 기존 Vite 주 청크 500kB 경고는 남아 있다.
- 뒤쪽 판은 도움 도구와 작품 모음을 보려면 세로 스크롤이 필요하다. 입력은 계속 가능하다.
