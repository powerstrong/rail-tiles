# 꿀벌 모바일 화면과 완료 카드 개선

## 변경 내용

- `src/lab/PuzzleScreen.tsx`, `src/lab/lab.css`: 휴대폰(600px 이하)에서 헤더 44px, 제목 18px, 도구 버튼 44px로 줄였다. 규칙은 제목 옆 버튼으로 열고, 화면 위에 겹치는 패널에서 읽는다. 화살표 꽃·다리 설명도 규칙 패널에 포함했다. 기본 화면의 이야기·중복 보드 설명과 보드 위 중복 꽃 수를 숨겼다. 꽃 수는 보드 아래 진행 줄에 남긴다.
- 꿀벌 보드는 가로 여유 폭과 세로 예산을 함께 고려한다. 바깥 테두리 10px을 제외한 높이에 행·열 비율을 곱해 폭 상한을 정한다: `min(가로 여유 폭, (100dvh - 280px) × (열 / 행) + 10px)`. 특히 21~32판 등에 포함된 6행×5열 보드도 같은 높이 안에 들어온다. 보드 테두리와 내부 여백을 줄이고 6×6 격자의 칸 사이 간격을 0으로 통일했다. 작은 화면에서도 칸을 줄이는 대신 설명·여백을 먼저 줄였다.
- 일반 피드백과 막힘 안내가 같은 72px 영역을 사용한다. 복구 버튼의 보이는 이름은 `풀 수 있던 곳으로 ↶`, 접근성 이름은 기존 `마지막으로 풀 수 있던 지점으로 되돌리기`다. 막힌 상태에서도 되짚기·되돌리기·처음부터·힌트를 조작할 수 있다.
- 거울 토끼에도 공통 헤더·제목·규칙 접기·메시지 영역·도구 크기 개선을 적용했다. 두 숲, 미리보기, 방향 조작, 숲 크게 보기 기능은 유지했다. 숲 크게 보기는 기존처럼 페이지 스크롤이 가능하다.

## 모든 월드의 완료 카드

`rg`로 완료 영역과 `ResultOverlay` 사용처, 축하 문구, 다음/목록 버튼을 전부 검색했다. `src/ui/StageCompletion.tsx`로 완료 내용과 포커스를 공통화했다.

적용 대상:

- 꿀벌·거울 토끼(`lab/PuzzleScreen`)
- 산호초·메모리·색깔 길 잇기·조각 맞추기·별사탕 저울·구름 자수
- 기차 및 들꽃 장치 노선(`ui/GameScreen`), 펭귄·차고지·우주·시계탑·기계·화산

완료 카드에는 별과 `다음 스테이지 →`, `스테이지 고르기`만 남겼다. 다음 판이 없으면 목록 버튼만 남는다. 축하 제목, 기록·힌트 설명, 단계 이름, 카드 내 다시 하기·닫기 버튼은 제거했다. 메모리의 엽서 그림은 남기고 엽서 설명과 장 완료 축하 문구는 제거했다. 구름의 별도 완성 작품 그림은 카드에서 제거했으며 완성 보드의 색과 작품 모음의 그림은 유지했다.

정보성 안내 판단: 새 월드 해금은 `새 여행지가 열렸어요.` 한 줄로 유지한다. 일일 퍼즐은 연속 완료 축하 부분을 빼고 `내일 새 …이 열려요` 정보만 유지한다. 메모리 장 종료 문구는 해금 정보가 아닌 축하이므로 카드에서 제거한다. 목록의 앨범·장 진행 정보와 작별 이야기는 그대로 둔다.

완료 카드에는 `aria-label="스테이지 완료"`를 유지했다. 다음 버튼이 있으면 그 버튼으로, 없으면 목록 버튼으로 포커스를 이동한다. 기존 월드의 `ResultOverlay`는 기존 연출 대기 이후 같은 버튼에 포커스를 준다. 새 입력 잠금이나 대기 타이머를 추가하지 않았다. 기존 성공 소리, 보드 효과, 별·색종이·꿀벌 반짝임과 연출 시간은 유지했다. 저장, 별 평가, 해금, 스테이지 데이터는 수정하지 않았다.

## 검증

Chromium에서 세 크기마다 50판 모두 검사했다(총 150개 레이아웃). 각 판의 시작·실제 한 걸음 이동·되돌리기 상태, 마지막 판의 힌트·막힘·복구·완료 상태를 검사한다. 가로·세로 페이지 넘침, 칸 크기, 보드와 도구의 화면 내 위치를 직접 측정한다. 막힘 전후 보드·도구 사각형이 정확히 같은지도 검사한다.

| CSS 뷰포트 | 검사한 판 수 | 모든 판 중 최소 칸 크기 | 도구 하단 최대 좌표 | 문서 높이 |
| --- | ---: | ---: | ---: | ---: |
| 390×844 | 50 | 60.66px | 706.88px | 844px |
| 360×740 | 50 | 55.66px | 670.88px | 740px |
| 320×568 | 50 | 48px | 558.05px | 568px |

세 크기 모두 페이지 스크롤 없이 보드·핵심 조작·막힘 안내와 44px 복구 버튼이 보인다. 최소 화면에서도 44px 예외는 필요하지 않았다. 320×568의 6×6 보드는 298×298px, 세로형 6행×5열 보드는 250×298px이며 둘 다 칸은 48×48px다. 실제 `dvh`와 행·열 비율로 크기를 계산하므로 세로형 보드가 정사각형 보드보다 길어지는 문제도 해결했다. 원본 판 크기는 5×5·5열×6행·6×6이며 50판 모두 원본 데이터를 그대로 쓴다.

회귀 검사에서는 모든 새 월드의 전 판 완료, 완료 버튼·포커스·설명 문구 부재, 메모리 엽서와 작품 모음, 별 저장·이전 기록 유지·순차 해금·오프라인 힌트·힌트 별 제한·토끼 확대·즉시 입력·축하 연출을 확인한다. 완료 카드 검증은 공통 `e2e/assertCompletion.ts`로 통일했다.

- `npm test`: 44개 파일, 991개 테스트 통과.
- `npm run build`: 통과. `npm run test:browser`에서도 같은 빌드를 다시 실행한다.
- `npm run test:browser`: 49개 테스트 전부 통과(최종 실행 3.3분).
- `git diff --check`: 통과.

390×844 캡처는 다음 경로에 저장하고 직접 열어 확인했다.

- `/tmp/ux1-shots/bee-50-playing.png`: 50판 진행 중
