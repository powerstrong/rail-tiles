## 꿀벌: 스크롤과 44px

Chromium의 CSS 뷰포트 기준이다. 각 크기에서 50판의 시작·실제 이동·되돌리기를 측정했다. 4~50판은 실제 불가능 경로로 들어가 막힘 안내를 표시하고 복구 버튼으로 돌아왔다. 1~3판은 전진 분기가 없는 입문판이므로 막힘 재현 대상에서 제외했다. 막힘 상태를 DOM으로 주입하지 않았다.

| 뷰포트 | 기본 배치 | 실제 막힘·복구 | 최소 칸 가로·세로 | 도구 하단 최댓값 | 문서 높이 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 390×844 | 50판 | 47판 | 60.66px | 706.88px | 844px |
| 360×740 | 50판 | 47판 | 55.66px | 670.88px | 740px |
| 320×568, 추가 검사 | 50판 | 47판 | 48px | 558.05px | 568px |

가로·세로 문서 넘침이 없고, 칸과 복구 버튼 높이는 44px 이상이다. 막힘 전후 보드·도구 사각형도 동일하다. 안내 하단이 도구 상단을 넘지 않는지 검사하며 실제 복구 클릭도 성공한다. 마지막 판에서는 힌트 표시, 복구, 완료 후 목록 버튼 포커스까지 확인한다. 5×5·5열×6행·6×6 원본 판 데이터는 변경하지 않았다.

390px·360px 막힘 캡처를 직접 열어 안내·복구 버튼·도구의 잘림과 겹침이 없음을 확인했다. 자동 측정 원본은 `/tmp/ux1-shots/measurements-{390x844,360x740,320x568}.json`이며, 각 판의 `stuck` 항목에는 추가한 막힘 상태 측정이 남는다. 별도 캡처는 `/tmp/ux2-shots/bee-50-stuck-{390,360,320}.png`다. `/tmp` 파일은 로컬 검증 자료이며 저장소 배포물에는 포함하지 않는다.

## 저장·해금·레이아웃 회귀

저장 스키마·해금 규칙·게임 모델·별 계산·판 데이터에는 `git diff HEAD` 변경이 없다. 브라우저 검사는 별 저장과 새로고침 후 유지, 이전 최고 별 보존, 순차 해금, 기존 보스 기록을 통한 원래 여행지 해금, 꿀벌 이전 30판 저장에서 31판 이어하기, 오프라인 힌트와 힌트 사용 별 제한을 포함한다.

다른 월드에서는 모바일 첫/마지막 판 배치·입력, 메모리 엽서와 구름 작품 모음, 토끼 양쪽 숲·확대, 기존 월드 완료 카드의 화면 내 위치를 확인한다. 서비스 워커의 기존 탭·지연 자산 보존과 하위 경로 오프라인 갱신 검사도 포함한다. 기존 8개 월드의 모든 판을 브라우저에서 전수 완료한 것은 아니며, 첫 판 실행과 전체 완료 분기 코드 대조로 검증했다.
