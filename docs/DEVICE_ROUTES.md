# 들꽃의 선택형 장치 노선

기본 노선 40판과 장치 노선 20판을 들꽃 스테이지 목록에서 선택합니다. 장치 노선은 기존처럼 `last-run` 뒤에 열립니다. 독립 로비 정거장은 제거했지만 내부 월드 ID `train2`, 남긴 스테이지 ID, 별 기록은 그대로입니다. 제외된 판의 저장된 별도 삭제하지 않습니다.

`t2-boss-1`은 장치 노선의 4번째 판입니다. 이 판에서 차고지·우주가 열리는 기존 조건을 유지하므로 새 플레이어에게도 더 늦어지지 않습니다. 거울 토끼·꿀벌은 처음부터 선택 가능합니다.

| 묶음 | 남긴 ID (진행 순) | 선택 이유 |
|---|---|---|
| 버튼·차단기 | `t2-first-gate`, `t2-crossing-detour`, `t2-gate-passenger`, `t2-boss-1` | 첫 버튼, 우회, 손님과 방문 순서, 실제 두 색 차단기 |
| 도개교 | `t2-drawbridge`, `t2-bridge-down`, `t2-lever-twice`, `t2-boss-2` | 내리기, 불필요한 레버 피하기, 다리를 건넌 뒤 레버, 손님과 강 건너기 |
| 급수 | `t2-water-tower`, `t2-two-towers`, `t2-tower-bridge`, `t2-desert-line` | 물 예산, 보충 위치 선택, 도개교와 결합, 손님 방문 중 급수 |
| 회전판 | `t2-turntable`, `t2-spin-around`, `t2-two-tables`, `t2-spin-water` | 상대 회전, 진입 방향, 두 회전판 연결, 물 예산과 회전 |
| 종합·화물 | `t2-first-wagon`, `t2-wagon-gate`, `t2-freight-line`, `t2-final-boss` | 연결 연출 소개 한 판, 차단기·급수·회전과 결합 |

한 번에 출발 보너스 5판, 화물 수만 늘리는 판, 장치가 있지만 제공 해답이 지나지 않는 이름뿐인 복합판을 우선 제외했습니다. 두 차단기를 요구한다고 했던 `t2-busy-crossing`과 파랑 장치가 불필요했던 `t2-two-colors`도 제외했습니다. `t2-boss-2`의 설명은 실제 경로의 레버·다리·손님으로 바로잡았습니다.

`season2.test.ts`는 20판의 성공 경로를 탐색 중단 없이 모두 열거하여 재생합니다. 제공 해답의 유효성·재고·최소 레일·별 분포를 확인하고, 모든 최단 경로가 묶음의 장치를 쓰는지 확인합니다. `t2-boss-1`은 모든 성공 경로가 두 색 차단기를 지나야 함을 검증합니다. 일부 소개판은 더 긴 우회 성공도 허용합니다. 최단 경로 검증을 모든 경로에서 장치가 필수라는 주장으로 확대하지 않습니다.

선별 기준은 새로운 선택을 남기는 편집 판단입니다. 탐색 깊이가 재미를 보장하지 않으므로 아이가 실제로 다시 해 보고 싶어 하는지는 관찰이 필요합니다.
