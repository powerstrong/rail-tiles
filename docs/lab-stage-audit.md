# 거울 토끼 · 꿀벌 스테이지 검증

각 30판, 총 60판의 전체 도달 상태를 열거했습니다. `npx vite-node scripts/lab-audit.ts`로 `lab-stage-audit.json`을 갱신합니다. 꿀벌의 되짚기는 복구 기능이므로 완주 가능성은 앞으로 이어 가는 이동만으로 판정합니다.

`npm test`는 꿀벌 30판의 모든 도달 상태에서 독립 DFS 결과와 완주 가능 집합을 대조합니다. 첫 3판은 모든 도달 상태에서 완주할 수 있습니다. 잘린 탐색과 표가 없는 상태는 미확인으로 처리합니다.

탐색 깊이는 재미의 증거가 아닙니다. 아이 관찰과 저사양 기기의 지연 실측은 별도로 필요합니다.
