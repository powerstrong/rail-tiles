# 거울 토끼 · 꿀벌 스테이지 검증

각 30판, 총 60판입니다. `npx vite-node scripts/lab-audit.ts`로 `lab-stage-audit.json`을 갱신합니다. 토끼는 전체 도달 상태를 열거합니다. 5×5/5×6으로 재생성한 꿀벌은 전체 경로 순서를 열거하지 않고 현재 칸과 방문 집합을 메모하여 전방 완주를 증명합니다. 되짚기는 복구 기능이므로 완주 탐색과 분리합니다.

`npm test`는 작은 분기 판의 모든 도달 상태를 독립적인 비메모 DFS와 대조하고, 꿀벌 30판의 정답 접두 경로와 그 갈림길을 검사합니다. 첫 3판에는 전방 선택 함정이 없습니다. 작업량·시간·메모리 상한을 넘으면 미확인이며, 불가능으로 단정하거나 입력을 막지 않습니다.

`npm run lab:generate`로 판을 재생성하고 `npm run lab:bee-audit`로 30판의 2만 회 무작위 완주율·실제 판단 수 및 Node/Chromium 성능을 기록합니다. 정의와 새 30판 요약은 [06 보고서](discussion/fun-triage/06_bee_5x5.md), 원시 측정은 [bee-5x5-audit.json](bee-5x5-audit.json)에 있습니다. 꿀벌의 예전 전체 상태 수(7,381개)는 이전 작은 판의 수치입니다.

탐색 깊이·무작위 실패율은 재미의 증거가 아닙니다. 아이 관찰과 저사양 실기기의 지연 실측은 별도로 필요합니다.
