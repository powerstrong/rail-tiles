# 실험실 스테이지 검증

고정 시드 `0x51ab2026`로 생성하고 선별한 10종 × 30판입니다. 생성은 개발 도구에서만 실행하며, 플레이할 때는 검증된 고정 데이터를 읽습니다.

모든 판의 해답을 엔진으로 재생하고 별도 탐색으로 다시 풀었습니다. 도토리·거울 토끼·반딧불·산호·모자이크의 기준 수는 최단 해답입니다. 저울·다리의 기준 수는 논리적 배치 횟수이며, UI의 순환 버튼 클릭 수와는 다를 수 있습니다. 자수와 다리는 단서만으로 해답이 하나인 판만 남겼습니다. 자수는 직접 그린 꽃·동물·탈것 등 30개 도안이며, 줄 겹침 추론만으로 끝까지 풀리는 판만 채택했습니다.

기준은 자수는 줄 추론 라운드 수, 저울은 카드 수, 다리는 섬 수, 그 외는 해답 행동 수입니다. 행동 수는 게임 사이의 난이도 비교가 아니라 같은 게임 안의 진행을 점검하는 지표입니다.

## 검증의 범위

- 모든 판은 미완성 상태로 시작하고 유효한 조작만으로 완료됩니다. 동일한 전체 판 데이터는 중복되지 않습니다. 고정 번호 모자이크와 좌우 반전 조작인 거울 토끼를 제외하면 회전·반사한 복제 판도 제외합니다.
- 밀기는 거꾸로 당기는 방식으로, 달돌은 거꾸로 돌을 늘리는 방식으로, 모자이크는 완성 상태에서 합법적으로 섞어 구성합니다.
- 벌길은 마지막 벌집 입장 규칙을 포함해 검증하며, 후반에는 실제 갈림길을 요구합니다.
- 달돌·벌길의 행동 수는 매번 돌이 하나 줄거나 방문 꽃이 하나 늘기 때문에 해답 길이가 고정됩니다. 저울·자수·다리의 기준 수는 배치 수이며 최단 클릭 수라고 주장하지 않습니다.
- 초기 상태 힌트 탐색의 방문 수를 기록하고 예산을 넘은 판은 제외합니다. 이 수치는 초기 상태에 대한 값이며 모든 임의 상태의 실행 시간을 보장하지 않습니다. 자수·다리는 단서 검증, 저울은 부분집합 열거, 반딧불은 선형대수로 풀며 이들의 visited 값은 그래프 탐색량과 직접 비교할 수 없습니다.
- 이 보고서는 풀 수 있음과 수학적 진행에 대한 검증입니다. 초등학생 대상 관찰 플레이를 대신하지 않으며, 재미·체감 난이도·읽기 편의성은 UI 점검과 사용자 피드백으로 더 조정해야 합니다.
