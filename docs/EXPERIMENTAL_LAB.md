# 거울 토끼 · 꿀벌

두 게임은 정식 월드로 편입되어 첫 노선도에서 바로 선택할 수 있습니다. 별·스테이지 해금·이어하기·기록 내보내기는 다른 정식 월드와 같습니다. 옛 실험실 도장은 완료만 기록했으므로 별 1개로 이어지며, 기존의 더 높은 별 기록을 보존합니다. 실험실 화면과 입구는 제거했습니다.

공유 규칙·보드·솔버는 `src/lab/`, 고정 60판 데이터는 `stages.generated.json`입니다. `npm run lab:generate`는 개발용 후보 생성이며 첫 꿀벌 3판은 수작업 입문 배치를 보존합니다. `npx vite-node scripts/lab-audit.ts`로 전체 도달 상태 감사를 갱신합니다.

★★★는 par 이하, ★★는 par+2 이하, 나머지 완료는 ★입니다. 힌트 사용 시 최대 ★★입니다. 꿀벌은 앞으로 길을 이을 때의 완주 가능성을 조회하고, 막힘이어도 입력을 잠그지 않습니다. 직전 칸을 누르거나 드래그해 되짚으면 한 칸만 지워집니다.

삭제된 후보 원본은 `archive/lab-v1`에 있습니다. `npm test`, `npm run build`, `npm run test:browser`를 실행해 공개 전 검증합니다. 탐색 깊이는 재미의 증거가 아니며 아이 관찰은 별도로 필요합니다.
